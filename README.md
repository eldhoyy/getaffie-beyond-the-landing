# BEYOND THE LANDING — Stories Left Behind by Space Exploration

**Team:** GETAFFIE  
**Tagline:** Every landing leaves a story.

An interactive digital museum exploring the hardware left behind by lunar and Martian landings. The site includes a landing-sequence explainer, filterable object archive, Moon-versus-Mars comparison, knowledge check and NASA reference links.

## Run locally
Open `index.html` in a modern browser. The site is a static, single-file HTML project and requires no build step. An internet connection is used only for the optional Google Fonts import and the linked NASA references.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for the deployment and visit `https://eldhoyy.github.io/getaffie-beyond-the-landing/`.
